# Источники и границы публикации

- `ai-service/`, `clients/`, `docs/` — «Проявитель», исходный проект этого репозитория.
- `picpac/` — PicPac на основе https://github.com/Liifert/picpac, базовый коммит `7bad48c8f1a9d973c7fa290dab535fbccfe90aa2`; локальные изменения: AI-помощник и передача заказов/фото в локальный раздел CRM.
- `platform/` — снимок исходников https://github.com/ch4mek/PhotoPrint с локальным разделом заказов PicPac. Вложенная Git-история не переносится; история исходного проекта доступна по ссылке.

Сторонние материалы, шрифты, изображения и библиотеки сохраняют свои исходные права. Общая новая лицензия не назначается; условия использования и права на материалы должны быть согласованы перед коммерческим распространением.

Рабочие `.env`, базы, фотографии покупателей, установленные зависимости и результаты сборки не публикуются. Конфигурации .NET `appsettings*.json` из исходного снимка не переносятся: вместо них добавлены примеры. Настройте необходимые параметры по контрактам самого backend. Очищенный NuGet.Config использует только nuget.org; приватные источники при необходимости настраиваются отдельно.

`platform/api` — исходный большой .NET backend; `platform/legacy-slice` — выделенный хакатонный срез. Корневой docker-compose внутри платформы ссылается на исходную структуру и не является проверенным запуском всего монорепозитория. Проверенный сквозной локальный сценарий — PicPac + раздел заказов React CRM, см. README и picpac/LOCAL-CRM.md.
