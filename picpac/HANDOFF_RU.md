# Передача PicPac для публикации

Версия 2.2.0. Полные исходники и готовая локальная сборка dist. В архив не включены node_modules, локальные фото, заказы, сессии и ключи доступа. Тестовые изображения интерфейса включены.

## Запуск на компьютере

Нужен Node.js 22.15 или новее. Распакуйте весь архив и откройте START_PICPAC.cmd. Адрес http://127.0.0.1:5174. Остановка STOP_PICPAC.cmd. Для разработки: npm ci, npm run build, node server.mjs. Проверки: npm test, npm run test:browser, npm run test:ui, npm run test:mascot. Браузерные проверки используют Edge в Windows либо путь PICPAC_BROWSER.

## Загрузить в свой GitHub

Создайте у себя пустой закрытый репозиторий. Из корня распакованного проекта выполните команды, заменив URL на свой:

```powershell
git init -b main
git add .
git commit -m "Import PicPac 2.2"
git remote add origin https://github.com/YOUR-ACCOUNT/picpac.git
git push -u origin main
```

Архив не содержит .git, поэтому авторизация и remote будут вашими.

## Что нужно учесть перед Vercel

Это готовая локальная версия, а не проверенное облачное развёртывание. Vite собирает интерфейс в dist. server.mjs обслуживает /api через server/mock-api.mjs и сохраняет состояние в .picpac-data/state.json. Простая публикация dist на Vercel откроет интерфейс, но не обеспечит вход, заказы и поддержку: их API нужно адаптировать и подключить постоянное хранилище. Не хранить облачную базу в локальном JSON функции и не считать /tmp постоянным хранилищем.

Оригиналы фото и черновики остаются в IndexedDB/localStorage конкретного браузера; между телефоном и компьютером не синхронизируются. Нужен HTTPS. Оплата, производство и поддержка учебные. Общая тестовая учётная запись не является защищённым пользовательским входом для реального сервиса. Никаких платных ресурсов автоматически не создавать.

## Текст для передачи другому чату

> В архиве PicPac 2.2: React 19, TypeScript, Vite, Node.js mock API. Изучи README.md, ACCEPTANCE.md, src/api.ts, server.mjs и server/mock-api.mjs. Нужно развернуть приложение через мой аккаунт Vercel. Сохрани существующий интерфейс, обучение с котиком, загрузку JPEG/PNG, редактор, восстановление черновика, проверку качества, корзину, идемпотентность тестового заказа, историю и обращения. Подготовь серверную часть к облаку с постоянным хранилищем. Используй доступные бесплатные варианты, до подключения платного ресурса спроси меня. Не публикуй секреты и реальные фотографии. Проверь полный путь от каталога до номера заказа на телефоне, а также повтор запроса без дубля. Не называй развёртывание готовым без проверки внешней HTTPS-ссылки.
