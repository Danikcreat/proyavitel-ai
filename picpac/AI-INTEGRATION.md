# Текстовый помощник PicPac

Перенесён подход из ../ai-service/app/providers.py и agent_provider.py: совместимый Chat Completions API, Bearer-ключ на сервере, проверка /models с часовым кешем, повторы временных HTTP-ошибок, таймаут и скрытые ответы провайдера. Зависимости агента и его ключ не копировались.

Настройка: AIAI_API_KEY, AI_BASE_URL и AI_MODEL из .env.example. Поддерживаются прежние псевдонимы AI_LLM_API_KEY, AI_LLM_BASE_URL, AI_LLM_MODEL. Укажите фактически доступную модель. Ключ добавляется только в Environment Variables проекта Vercel; затем redeploy. Локально: npm ci, npm run build, node --env-file=.env server.mjs. Проверки: npm test и node --test tests/album-ai.test.mjs.

В редакторе откройте «Макет» → «Собрать альбом с ИИ». Добавьте фото, опишите последовательность и тему, проверьте предложение и примените его. Результат хранится в черновике, попадает в корзину вместе с проектом и отменяется через undo. Редактирование макета, подписи и фона меняет выбранный разворот. После перестановки фото номера означают их текущий порядок. Сами изображения, имена файлов, контакты и API-ключ в модель не отправляются. Модель не анализирует изображения и не генерирует новые.

Без ключа/модели сервер возвращает 503 с понятным сообщением. На один экземпляр функции допускается 2 параллельных запроса и 10 запросов в минуту; это защита демоверсии, не общий лимит расходов. До публичного использования платного ключа настройте авторизацию и распределённые квоты (либо защиту доступа к развёртыванию), а у провайдера — лимит бюджета. Квоты Проявителя зависят от его базы и JWT и сюда автоматически не переносятся.

Это подготовленный локальный код, не изменение опубликованного сайта. Исходники взяты из Liifert/picpac на коммите 7bad48c8f1a9d973c7fa290dab535fbccfe90aa2. Для применения к форку используйте ai-integration.patch. Исходные PNG/шрифты/SVG восстановлены из полного архива. scripts/check-assets.mjs проверяет размеры и Git blob SHA всех 89 статических файлов перед сборкой. Крупные двоичные файлы при прямой публикации API загружаются через upload_file и включаются в deployment по SHA1 и размеру. Существующий mock API заказов требует отдельного постоянного хранилища для Vercel и здесь не переработан.
