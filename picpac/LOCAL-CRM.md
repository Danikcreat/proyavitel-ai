# PicPac ↔ CRM: локальный демонстрационный режим

PicPac: http://127.0.0.1:5174
CRM, раздел заказов: http://127.0.0.1:3000

Запуск PicPac из этой папки: `PICPAC_LOCAL_CRM=true node server.mjs`.
Запуск CRM из ../platform/web: `npm start -- --host 127.0.0.1 --port 3000 --strictPort`.
Файл platform/web/.env.local содержит VITE_LOCAL_CRM=true. Режим без входа работает только в Vite dev и на localhost/127.0.0.1. Удалите эту настройку, чтобы вернуть исходную маршрутизацию.

На этом устройстве CRM читает подтверждённые заказы из API PicPac. Данные сохраняются в .picpac-data/state.json, исходники JPEG/PNG — в .picpac-data/photos/<userId>. Полный исходный запрос сохраняется в originalRequest, параметры, макеты и план ИИ — в items[].draft. Файлы отправляются только при оформлении заказа, до подтверждения сервером; если передача не удалась, заказ остаётся в очереди. Повтор использует прежний ключ идемпотентности. Статус из локальной CRM доступен покупателю через API истории заказов. Удаление аккаунта удаляет также исходники.

Проверка реальной связки: `node scripts/smoke-local-crm.mjs` при работающих обоих серверах. Создаёт явно отмеченный тестовый заказ без оплаты; повтор не создаёт дубликат. Проверяет исходный запрос, PNG побайтно и статусы.

Это раздел локальных заказов внутри React-приложения CRM и общее постоянное локальное хранилище, а не интеграция с .NET/MySQL основного backend PhotoPrint. Остальные модули платформы требуют его установки и настройки. На публичном Vercel локальный обход входа и CRM-маршруты не включены. Существующий опубликованный PicPac не менялся этим заданием; для проверки используйте адрес 5174.

## Доступ с телефона
Текущий Wi-Fi IP: 172.20.10.10. PicPac: http://172.20.10.10:5174, CRM: http://172.20.10.10:3000.
Запуск для LAN: `PICPAC_LOCAL_CRM=true PICPAC_ALLOW_LAN=true PICPAC_HOST=0.0.0.0 node server.mjs`; CRM: `npm start -- --host 0.0.0.0 --port 3000 --strictPort`.
В режиме LAN CRM без входа доступна всем устройствам вашей частной сети. IP может меняться при смене Wi-Fi. Не настраивайте проброс портов в интернет.
